# 🌙 Suwaya (سُويعَة)

An advanced Islamic time management and productivity app built with Flutter. Suwaya beautifully bridges the gap between Astronomical time (Suwayas/Periods) and Civil time (Hours/Minutes), helping users align their daily routines, focus sessions, and worship with the natural rhythm of the sun.

## ✨ Key Features
* **Dual Time Engine:** Seamlessly operates on both Astro Time (7 Islamic Periods) and Civil Time.
* **Global Reach:** Fully localized into **22 languages** with dynamic UI rendering and RTL/LTR support.
* **Smart Productivity:** Built-in Pomodoro timer logically synchronized with the current "Suwaya".
* **Interactive Dials:** Custom-painted, highly interactive astronomical dials for tracking tasks, habits, and prayers.
* **Offline-First & Cloud Sync:** Powered by local caching (Isar) and real-time Supabase synchronization.
* **Advanced Astro Calculations:** Supports precise GPS-based calculations and multiple global Islamic conventions.

## 🛠️ Tech Stack
* **Framework:** Flutter
* **State Management:** Riverpod
* **Backend:** Supabase
* **Localization:** Easy Localization
* **Local Storage:** Isar Database
