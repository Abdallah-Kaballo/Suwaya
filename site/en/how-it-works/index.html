The model in numbers

How does Suwaya Time work?

The core calculation is straightforward: determine the cycle anchors, then divide the physical duration between two anchors into a configured number of Suwayas. A virtual Suwaya minute is therefore not a fixed civil minute; its duration follows the interval length and its allocation.

The core equations

Physical duration per Suwaya = interval duration ÷ allocated Suwayas
Civil duration per virtual minute = interval minutes ÷ (allocated Suwayas × 60)
Flow speed = 60 virtual minutes ÷ physical minutes per Suwaya

If one Suwaya occupies 30 civil minutes, each virtual minute occupies 30 civil seconds and the flow speed is 2×. If one Suwaya occupies 90 civil minutes, each virtual minute occupies 90 civil seconds and speed is about 0.667×.

A reproducible numerical example

Assume an interval lasting 180 civil minutes is allocated 6 Suwayas. This is an illustrative arithmetic example, not a claimed astronomical result for a particular city and date.

180 ÷ 6 = 30 civil minutes per Suwaya
30 ÷ 60 = 0.5 civil minutes per virtual minute = 30 seconds
60 ÷ 30 = 2× flow speed

For comparison, a 360-minute interval allocated 6 Suwayas yields 60 civil minutes per Suwaya, one civil minute per virtual minute, and 1× speed.

How the cycle is built

  1. Resolve coordinates, date, time zone, calculation method, and madhab settings.
  2. Calculate anchors such as Maghrib, Isha, Islamic midnight, Fajr, sunrise, Dhuhr, Asr, and the next Maghrib.
  3. Divide the cycle into seven contiguous periods and assign each a configured number of Suwayas.
  4. Map physical time within each period to virtual minutes and seconds, with reverse conversion to a physical instant.

Outputs depend on inputs and calculation settings. The arithmetic example above is not a validation of prayer-time accuracy.

Keep three concepts separate

  • Astronomical anchor: a calculated event such as sunrise or sunset, under a model and parameters.
  • Religious or conventional time definition: for example, the definition of Islamic midnight or a chosen Fajr/Isha calculation method.
  • Software allocation: the number of Suwayas assigned to each interval. This is a design decision, not an astronomical fact.
The arithmetic is manually verifiable. Claims that the model is “more accurate” or “more natural” require a defined metric and independent evidence; this page makes no such claim.
